# Research Workflow

## Purpose
Conduct structured research on a given topic and save findings to /output.

## Steps

1. **Clarify** - Ask the user:
   - What is the research topic?
   - What is the goal or decision this research supports?
   - Any sources to include or exclude?
   - Desired output format (summary, bullets, report)?

2. **Plan** - Show the user:
   - What you will research
   - What sources you will consult
   - What the output will look like

3. **Research** - Gather information:
   - Use web search for current information
   - Prioritize primary sources
   - Note the URL and date for every source

4. **Synthesize** - Distill findings:
   - Extract only what is relevant to the goal
   - Use clear bullet points
   - Flag conflicting information

5. **Save** - Write output to `/output/<topic>-research.md`:
   - Summary (3-5 bullets)
   - Key findings (bulleted, specific)
   - Sources (title, URL, date accessed)

## Output Template

```
# Research: <Topic>
Date: <YYYY-MM-DD>

## Summary
- <bullet>

## Key Findings
- <bullet>

## Sources
- [Title](URL) — accessed <date>
```
